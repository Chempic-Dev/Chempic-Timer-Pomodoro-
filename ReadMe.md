# Chempic Timer(Pomodoro)

The Best Pomodoro Timer extension for VSCode with work/break cycles.

## Features

- 🍅 25minute work sessions
- 😴 5minute break sessions  
- Visual status bar indicator
- Notifications when time is up
- One-click start/stop

## How to Use

1. Click the "🍅 Pomodoro" button in the status bar to start a work session
2. When the timer finishes, click "😴 Отдых?" to start a break
3. Enjoy your productive workflow!

No way, everything is ready out of the box😌.
